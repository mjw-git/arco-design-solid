# 链接 Link

链接的基本样式。

## 基础用法

与按钮相比，链接不太突出，因此通常将其用作可选操作。
<demo src="link/index.tsx"  github='Link'></demo>

## 其他状态

失败、警告、成功等其他状态下操作，可出现不同样式的链接。
<demo src="link/status.tsx"  github='Link'></demo>

## 图标

通过 Icon 属性设置带图标的链接，设置为 true时候显示默认图标。
<demo src="link/icon.tsx"  github='Link'></demo>

## 悬浮状态样式

可以通过 hoverable 属性设置是否在悬浮状态时隐藏底色。
