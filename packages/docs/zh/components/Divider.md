# 分割线 Divider

划分内容区域，对模块做分隔。

## 基本用法

对不同章节的文本段落进行分割，默认为水平分割线，可在中间加入文字。
<demo src="divider/index.tsx"  github='Divider'></demo>

## 带有文字的分割线

通过 orientation 指定分割线文字的位置。
<demo src="divider/text.tsx"  github='Button'></demo>

## 竖直分割线

指定 type 为 vertical 即可使用竖直分割线。竖直分割线不能带文字。
<demo src="divider/vertical.tsx"  github='Button'></demo>
